# Runtime dependencies. This file is what SAM installs into the Lambda package, so
# keep it to what production actually needs — anything here ships to AWS and adds
# to cold-start time.
#
# boto3 is deliberately absent: the Lambda runtime already provides it. Install it
# locally (pip install -r requirements-dev.txt) if you exercise the DynamoDB path
# on your machine.

# Claude: the strategy, the social analysis (with server-side web search/fetch) and
# the campaign recommendations. The official SDK, which also retries 429/5xx.
anthropic>=1.8,<2

# Mints Google access tokens from the service-account key. Tokens live one
# hour, so a pasted token cannot work in production.
google-auth>=2.28

# Draws the campaign report's bar charts to PNG. python-bidi reorders mixed
# Hebrew/Latin chart labels for correct display.
Pillow>=10.2

# The campaign report PDF is printed by headless Chromium. On Lambda that is the

# needed here. Playwright — for rendering on a laptop — lives in
# requirements-dev.txt: its bundled Node is 118 MB, which is what nearly pushed
# the function past Lambda's 250 MB limit.

# Inflates the Chromium layer's Brotli archives on Lambda (src/lib/pdf_chromium.py).
brotli>=1.1
